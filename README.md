# EED Salapao Website v3.1.0

เวอร์ชันนี้เน้นความน่าเชื่อถือและความสมดุลของหน้าแรก

## วิธีอัปโหลด
1. แตก ZIP
2. อัปโหลดไฟล์ทั้งหมดทับไฟล์เดิมใน GitHub
3. Commit changes
4. รอ GitHub Pages Deploy
5. กด Ctrl + F5
